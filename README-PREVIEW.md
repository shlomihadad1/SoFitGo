# Fit30 Premium — Preview "Innovation" (שלבים D–G, על בסיס שלב C)

זו גרסת בדיקה. **אין לפרסם אותה לאתר החי** לפני שתאשר.

## הפעלה

1. בתיקייה `app/` מריצים `python3 -m http.server 8080`.
2. פותחים `http://localhost:8080`.

אפשר גם להעלות לכתובת HTTPS נפרדת, למשל אתר Netlify חדש. הנתונים בדפדפן נשמרים לפי כתובת, כך שבכתובת חדשה הם יתחילו ריקים. כדי לראות שם את הנתונים הקיימים: באתר הקודם עושים הגדרות ← ייצוא גיבוי, ובכתובת החדשה מבצעים שחזור.

## מה לבדוק

1. **משתמש חדש:** בדפדפן נקי, או אחרי ניקוי נתוני האתר, מסך הבית מציג "בונים תוכנית אישית". לוחצים "להתחלה" ועוברים 6 שלבים. אפשר לחזור אחורה בכל שלב, והנתונים נשמרים.
2. **התוכנית שלי:** אימונים ← התוכנית האישית. כאן אפשר להשהות ולהמשיך, לשנות ימים וזמן או ציוד (עם תצוגת הבדלים), לעבור לתוכנית אחרת או לבטל.
3. **יום בתוכנית:** בוחרים גרסה (קצרה, רגילה או ארוכה), מחליפים תרגיל, מעבירים ליום אחר, מדלגים, או מתחילים אימון.
4. **משתמש קיים:** משחזרים גיבוי מהגרסה הנוכחית. כל הנתונים צריכים להישמר, והיעדים צריכים להישאר זהים.
5. **שלב A:** מסלולים (תצוגה מקדימה), ובהגדרות "מצב מדיה ורישיונות".
6. **תפריט אישי (שלב C):** אחרי הפעלת תוכנית, במסך תזונה מופיע "תפריט אישי לפי התוכנית". אפשר לדפדף לכל יום בתוכנית, כולל ימים רחוקים בתוכנית של שנה.
7. **החלפות:** "החלפה" בארוחה, החלפת מרכיב ו"גודל מנה" — לפני האישור מוצגת טבלה עם קלוריות, חלבון, פחמימות ושומן לפני ואחרי.
8. **העדפות:** הגדרות ← העדפות תזונה (למשל טבעוני + בלי סויה) ← שמירה. התפריט מתעדכן מהיום הפתוח הראשון. כשאין מנה מתאימה מוצג פער, לא מנה שלא מתאימה.
9. **שינוי יעד:** משנים משקל בפרופיל. התפריט לא משתנה לבד; מופיע באנר "עדכון התפריט", ורק אחרי אישור הימים הבאים מחושבים מחדש. ארוחות שנאכלו לא משתנות.
10. **מתכונים:** מסנן "בינלאומי" (63), ודף מתכון עם תיאור, מטבח, אלרגנים ואופן חישוב הערכים.
11. **שלב D:** בית (המאמן היומי, רצועת שבוע), לוח התוכנית, "התוכנית שלי" במסך האימונים, מתכונים עם חיפוש ו"הצגת עוד", שורת קפיצה בפרופיל ובהגדרות.
12. **שלב E:** דף תרגיל — "פרטי התרגיל" ו"דגשי בטיחות"; דף מתכון — סטטוס מדיה חסרה.
13. **שלב F:** אחרי שני אימונים שנרשמים דרך "התחלת אימון" מופיעות "התאמות מוצעות לתוכנית" (בית ומסך התוכנית): פרטים ← אישור ← תג "מותאם" ביום ← "ביטול ההתאמה".
14. **שלב G:** "למה התוכנית כזו?", "סיכום שבועי", "שיאים", "רשימת קניות", ו"מצב נסיעה / בלי ציוד" במסך התוכנית.

## בדיקות אוטומטיות

הבדיקות רצות מתוך `source/`, עם Node ו־Playwright, ושרת שמגיש את `dist/pwa` בפורטים 8091 ו־8096:

```
node tools/build.js
node tools/build_check.js
node tools/content_test.js
node tools/stageA_test.js
node tools/stageB_test.js
node tools/stageC_test.js
node tools/e2e.js
node tools/e2e_stageA.js
node tools/e2e_stageB.js
node tools/e2e_stageC.js
node tools/stageC_report.js   # writes STAGE-C-REPORT.md
sh tools/run_all.sh            # D–G: builds, then runs every suite (incl. stageD–G, soak_test)
node tools/innovation_report.js  # writes PREVIEW-INNOVATION-REPORT.md
```

כל הבדיקות האלה רצות ב־Chromium באמולציה. זו לא בדיקה במכשיר iPhone פיזי.

הדוח המלא של השלב: `STAGE-C-REPORT.md` (תוצאות, רשימת המתכונים, טבלת 30 ימים, גיוון ומגבלות).

דוח שלבים D–G: `PREVIEW-INNOVATION-REPORT.md`; דירוג התכונות: `G-AUDIT.md`; יומן התקדמות: `DG-PROGRESS.md`.
