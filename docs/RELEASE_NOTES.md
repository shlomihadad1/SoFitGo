## חדש
- **מכונת מצבים לאימון:**
  - שמונה מצבים, ושמירה אחרי כל פעולה;
  - "נקטע" אחרי סגירה (יותר מ־60 שניות) או אחרי רקע ארוך (יותר מ־15 דקות), בלי לספור את הזמן שבחוץ;
  - שמירה פעם אחת בלבד.
- **Workout Builder:** בניית אימון לפי מטרה, זמן, רמה וציוד; עריכה, שכפול, מועדפים וחזרה למקור.
- **החלפת תרגילים חכמה:** דירוג אחד לתוכניות ול־Builder, לפי ציוד, תבנית תנועה, שרירים, רמה, החרגות וקפיצות.
- **מרכז פרטיות:** מה נשמר ואיפה, שירותים חיצוניים, הרשאות, ייצוא CSV לכל נושא, גיבוי JSON ומחיקה.
- **ממשק ניהול:**
  - לשונית "משוב ותקלות" (סטטוס, הערת צוות, יומן);
  - לשונית "חשבונות" (מספרים מצטברים בלבד).
  - ההרשאה נבדקת בשרת. **לא הופעל בשרת החי.**
- **אפליקציית Android לבדיקה (APK):** אותו build, בלי שרת. קבצים נשמרים בתיקיית ההורדות, והמסך נשאר דלוק באימון.
- **מדריכים:** למנהל, למשתמש, התחלה מהירה, תקלות ידועות, התקנה ועדכון.
