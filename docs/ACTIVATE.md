# הפעלת SoFitGo עם מערכת ניהול — 6 צעדים

**מה יש לך:**
- **`sofitgo-deploy-74bdd9483f.zip`:** האתר המוכן, מחובר ל־Supabase שלך. בתוכו רק המפתח הציבורי (publishable).
- **`activate_admin.sql`:** מפעיל את מערכת הניהול. רץ בפעם אחת: הכול או כלום. אפשר להריץ אותו פעמיים בלי נזק.
- **`make_owner.sql`:** הופך אותך לבעלים.
- **`undo_admin.sql`:** ביטול, אם צריך.

## 1. גיבוי (2 דקות)
Supabase ← Database ← Backups ← לוודא שיש גיבוי מהיום.

אם אין גיבוי בתוכנית שלך, ראו `docs/SUPABASE_ADMIN_ACTIVATION.md` סעיף 1: גיבוי לקובץ במחשב.

## 2. הפעלת מערכת הניהול
Supabase ← **SQL Editor** ← New query ← מדביקים את כל `activate_admin.sql` ← **Run**.
- **הצלחה:** "Success. No rows returned".
- **אם מופיעה שגיאה:** שום דבר לא השתנה. שולחים לי את הודעת השגיאה.

## 3. כתובת האתר לאימות מייל
Supabase ← **Authentication ← URL Configuration**:
- **Site URL:** `https://sofitgo.com`.
- **Redirect URLs:** להוסיף `https://sofitgo.com/**`.
- שומרים.

## 4. פריסה
1. פורקים את `sofitgo-deploy-74bdd9483f.zip`.
2. Netlify ← האתר ← **Deploys** ← גוררים את התיקייה `sofitgo`.
3. **בדיקה:** פותחים `https://sofitgo.com/sw.js`, ובו צריך להופיע `fit30-74bdd9483f`.

## 5. הרשמה והפיכה לבעלים
1. `https://sofitgo.com/#/account` ← נרשמים עם המייל שלך ← מאשרים את המייל שקיבלת.
2. SQL Editor ← מדביקים את `make_owner.sql` ← מחליפים את `YOUR-EMAIL` במייל שלך (פעמיים) ← **Run**.
3. בתוצאה צריכה להופיע שורה אחת: המייל שלך ו־`owner`.

## 6. כניסה לניהול
`https://sofitgo.com/#/admin`. בראש המסך יופיע **"מחובר/ת כ־בעלים"**.

**הלשוניות:**
- **ניהול תוכן:** מתכונים, תרגילים, טקסטים, פריסת מסכים, עיצוב והגדרות. תמיד בזרימה: טיוטה, אחר כך "בדיקה ופרסום", ואפשר לחזור לכל גרסה.
- **צוות:** בלשונית **הרשאות** מוסיפים אנשי צוות לפי מייל.
- **משתמשים:** **משוב ותקלות** (דיווחים מהמשתמשים) ו**חשבונות** (מספרים מצטברים).
- **מעקב:** **יומן שינויים** (מי עשה מה) ו**מצב מערכת**.

המדריך המלא: `docs/ADMIN_USER_GUIDE.md`.

## ביטול
- **מערכת הניהול:** SQL Editor ← `undo_admin.sql`. תוכן שפורסם דרך הניהול, התפקידים וההערות נמחקים. חשבונות, נתוני משתמשים ודיווחים נשארים.
- **האתר:** Netlify ← Deploys ← הפריסה הקודמת ← **Publish deploy**.

## גיבוי מפתח Android (פעם אחת)
1. ב־Mac מריצים:
   - `brew install age`
   - `age-keygen -o ~/sofitgo-backup.key`
2. הפקודה מדפיסה שורה שמתחילה ב־`age1`. **שולחים לי רק אותה.** את הקובץ `~/sofitgo-backup.key` שומרים במנהל סיסמאות.
3. אני שולח קובץ מוצפן. בודקים שהשחזור עובד:
   - `age -d -i ~/sofitgo-backup.key sofitgo-android-key.tar.age | tar -tvf -`
   - צריכים להופיע שני קבצים.
4. מאשרים לי שהשחזור עבד. עד אז המפתח בסביבה לא נמחק ולא משתנה.
