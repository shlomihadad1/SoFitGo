# התחלה מהירה — SoFitGo Beta

1. **פותחים** את האפליקציה: בדפדפן או באפליקציית Android לבדיקה. ההוראות ב־`docs/BETA_INSTALL_AND_UPDATE.md`.
2. **בית ← "הגדרת פרופיל ותוכנית":** ממלאים גיל, גובה, משקל, ניסיון, מטרה, ימים וציוד, ואז **הפעלת התוכנית**.
3. **אימונים:** בוחרים את האימון של היום ← **התחלת אימון** ← **סיימתי סט** אחרי כל סט. בסוף: ✕ ← **סיום האימון עכשיו (סיכום)** ← **שמירת האימון**.
4. **תזונה:** בכל ארוחה לוחצים **סמן שאכלתי**, או **החלף מנה** אם רוצים משהו אחר.
5. **בית:** מוסיפים מים בכפתורי הליטרים.
6. **מעקב:** משקל, **סיכום שבועי** ו**שיאים ואבני דרך**.
7. **גיבוי:** הגדרות ← **מרכז פרטיות וייצוא נתונים** ← **גיבוי מלא (JSON)**. מומלץ פעם בשבוע.

**טוב לדעת:**
- הכול נשמר במכשיר.
- אימון שנסגר באמצע ממשיך מאותו מקום.
- ‏Sofit עונה לפי כללים, לא באמצעות AI.
