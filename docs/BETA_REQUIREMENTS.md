# SoFitGo Beta — רשימת דרישות מאוחדת

**עודכן 25.10.2026.** ענף `fix/default-cuisine`, קוד ב־commit ‏`0a3d469`, build ‏`86ee62daec`.

**מקורות:**
- `docs/FEATURE_REGISTRY.md` (מזהי FR) ו־`docs/SOFITGO_MASTER_REQUIREMENTS.md` (§ = סעיף שם).
- `docs/WORKOUT_SESSION_STATE_MACHINE.md` ו־`docs/DEVICE_TEST_PLAN.md`.
- הדרישות של הבעלים בשיחות. לא הומצאו כאן החלטות מוצר חדשות.

**כללים:**
- כל "A" נשען על בדיקה אוטומטית שעברה, ושמה מופיע בשורה.
- כל הבדיקות האוטומטיות הן אמולציה (Chromium או WebKit עם פרופיל iPhone 13), **לא מכשיר פיזי**.
- העמודה "מכשיר" מסמנת אם נדרשת בדיקה ידנית בטלפון (`DEVICE_TEST_PLAN.md`).

**מקרא:**
- **A** — ממומש ומאומת.
- **B** — ממומש חלקית.
- **C** — חסר.
- **D** — ממומש, אבל לא נבדק מספיק.
- **E** — חסום: שירות חיצוני, הרשאה, מכשיר או עלות.
