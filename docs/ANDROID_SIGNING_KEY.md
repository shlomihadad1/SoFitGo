# מפתח החתימה של אפליקציית Android לבדיקה

## למה זה חשוב
Android מתקין עדכון רק אם הוא חתום **באותו מפתח** כמו הגרסה שכבר מותקנת.

**אם המפתח אובד:**
- אי אפשר לעדכן את האפליקציה.
- צריך להסיר אותה, וזה מוחק את הנתונים שבתוכה.
- לפני הסרה כזו: גיבוי JSON במרכז הפרטיות, ושחזור אחרי ההתקנה.

## איפה המפתח נמצא עכשיו
- **מיקום:** תיקייה זמנית של סביבת העבודה, `…/scratchpad/android-key/`.
- **קבצים:**
  - `beta.jks`: הרשאות 600.
  - קובץ סיסמה: הרשאות 600, נדרש לחתימה בסביבה הזו. **זה טקסט רגיל ליד המפתח.** הוא לא יצא מהסביבה בצורה הזו.
- **לא ב־repo:** לא ב־ZIP, לא ב־APK, לא במסמכים ולא בצ'אט.
- **שום דבר לא נמחק או הועבר** עד שתאשר שגיבוי מוצפן נבדק.
- **התיקייה לא קבועה.** היא נמחקת כשהסביבה מתאפסת. לכן צריך גיבוי מחוץ לה. זו פעולה שלך.

## גיבוי מוצפן — בלי סיסמה בצ'אט ובלי טקסט רגיל
**השיטה:** אתה שולח **מפתח ציבורי** של age, שאינו סוד. אני מצפין אליו את המפתח ואת הסיסמה יחד, לקובץ אחד. רק המפתח הפרטי שלך, שנשאר אצלך, יכול לפתוח אותו.

1. **אצלך במחשב:**
   - מתקינים age, כלי חינמי (ב־Mac: `brew install age`; ב־Windows: מ־GitHub ‏FiloSottile/age).
   - מריצים `age-keygen -o sofitgo-backup.key`.
   - הפקודה מדפיסה שורה שמתחילה ב־`age1…`. **זה המפתח הציבורי.** שולחים לי רק אותו.
   - את הקובץ `sofitgo-backup.key` שומרים במנהל סיסמאות או בכונן מוצפן. **לא לשלוח אותו.**
2. **אצלי:** מכין `sofitgo-android-key.tar.age`, ובתוכו `beta.jks` וקובץ הסיסמה, מוצפנים למפתח הציבורי שלך.
   - שולח אותו כקובץ.
   - או, אם המחשב מקושר לשיחה, כותב אותו לתיקייה שבחרת.
   - **הקובץ המוצפן לבדו לא חושף כלום.**
3. **אצלך:**
   - שומרים את הקובץ המוצפן בשני מקומות, למשל בענן ובכונן חיצוני.
   - את קובץ המפתח הפרטי שומרים **בנפרד** מהם.

## בדיקת שחזור (חובה לפני שמאשרים)
```
age -d -i sofitgo-backup.key -o restore.tar sofitgo-android-key.tar.age
tar -xf restore.tar
```
התוצאה: `beta.jks` וקובץ סיסמה.

אחר כך מריצים את הבדיקות בסעיף הבא. כשטביעת האצבע תואמת:
- מעבירים את הסיסמה למנהל הסיסמאות;
- מוחקים את `restore.tar` ואת קובץ הסיסמה הפתוח.

רק אחרי זה מאשרים לי שהגיבוי נבדק.

## איך מוודאים שהגיבוי ניתן לשחזור
במחשב עם JDK:
```
keytool -list -v -keystore beta.jks -alias sofitgo-beta
```
מקלידים את הסיסמה כשמתבקשים. הפקודה צריכה להציג את טביעת האצבע SHA-256 שבטבלה למעלה.

ובדיקה מול APK חתום:
```
apksigner verify --print-certs sofitgo-beta-<build>-<commit>.apk
```
השורה `Signer #1 certificate SHA-256 digest` צריכה להתאים לאותה טביעת אצבע. אפשר להשוות בלי נקודתיים, באותיות קטנות.

**המקור בסביבה לא יימחק ולא יועבר לפני שאישרת שהגיבוי נבדק.**

## אם המפתח כבר אבד
1. יוצרים מפתח חדש: `keytool -genkeypair -alias sofitgo-beta -keyalg RSA -keysize 3072 -validity 10000 -keystore beta.jks`.
2. בונים מחדש עם `build_apk.sh`.
3. בכל טלפון: גיבוי JSON ← הסרת האפליקציה ← התקנה ← שחזור.

## לפני חנות Google Play
