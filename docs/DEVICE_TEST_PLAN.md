### דרך א — HTTP ברשת הביתית
1. המחשב והטלפון צריכים להיות מחוברים לאותה רשת Wi‑Fi.
2. פרקו את ה־ZIP במחשב. בתוך התיקייה `sofitgo` הריצו: `python3 serve_beta.py`. ב־Windows: `py serve_beta.py`.
3. השרת מדפיס כתובת, למשל `http://192.168.1.23:8080/`. פתחו אותה בטלפון: ב־Safari באייפון, ב־Chrome באנדרואיד.
4. אם הטלפון לא מצליח להתחבר, אשרו את Python בחומת האש של המחשב, לרשת פרטית בלבד.
5. כשמסיימים, סגרו את השרת עם Ctrl+C.

### דרך ב — Android עם כבל USB
1. בטלפון: הגדרות → אודות → לחצו 7 פעמים על "מספר Build". אחר כך: אפשרויות מפתח → ניפוי באגים ב־USB.
2. במחשב: הריצו `python3 serve_beta.py`. בכרום של המחשב פתחו `chrome://inspect/#devices`, לחצו Port forwarding והוסיפו `8080` → `localhost:8080`.
3. בכרום שבטלפון פתחו `http://localhost:8080/`.

### דרך ג — iPhone עם HTTPS
1. במחשב: התקינו את mkcert, כלי חינמי (ב־Mac: `brew install mkcert`). הריצו `mkcert -install`, ואחר כך `mkcert <IP של המחשב>`. נוצרים שני קבצי ‎`.pem`‎.
2. מצאו את תעודת השורש של mkcert (‏`mkcert -CAROOT` מראה איפה) ושלחו את `rootCA.pem` לאייפון, למשל ב־AirDrop.
3. באייפון: הגדרות → כללי → VPN וניהול מכשירים → התקנת הפרופיל. אחר כך: הגדרות → כללי → אודות → הגדרות אמון בתעודות → הפעילו אמון מלא.
4. במחשב: `python3 serve_beta.py --https <ip>.pem <ip>-key.pem`. באייפון פתחו `https://<IP>:8443/`.
5. בסיום הבדיקות, הסירו את הפרופיל מהאייפון.

## 2. בדיקות — מה כבר עבר באמולציה ומה דורש מכשיר

**מקרא:**
- **E** = עבר באמולציה (‏Playwright, ‏Chromium/WebKit עם פרופיל iPhone 13).
- **S** = הודמה באמולציה בלבד: שעון מדומה, או רשומה שהוזזה אחורה בזמן.
- **D** = דורש מכשיר פיזי.

### מה רושמים לכל בדיקה
מכשיר וגרסת מערכת, דפדפן, דרך ההפעלה (א/ב/ג), תוצאה (עבר / נכשל / לא בוצע) וצילום מסך במקרה של כשל. אפשר לשלוח מתוך האפליקציה: "משוב" → תיאור.

## 3. מה לא ניתן לבדוק כאן ולמה
- נעילת מסך אמיתית, השהיית האפליקציה על ידי iOS או Android, והפעלה מחדש של מכשיר: אין מכשיר פיזי בסביבת הבדיקה. האמולציה מדמה רק "דף קפוא שחוזר".
- Wake Lock, צליל ורטט: דורשים חומרה.
- התקנה למסך הבית ו־Service Worker עם תעודה מאושרת בטלפון.
- אין ריצה ברקע: כשהאפליקציה מושהית, הטיימרים לא רצים. בחזרה הם מחושבים מחדש מזמנים מוחלטים.
